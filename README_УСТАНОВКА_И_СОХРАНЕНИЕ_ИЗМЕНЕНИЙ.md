# Mirror-info — пакет доработок (FB2 + EPUB + счётчик + калькулятор/админка)

Этот ZIP — пакет безопасного внедрения для репозитория `Lina1209/Mirror-info-`.
Он НЕ заменяет весь сайт и не перезаписывает текущие файлы автоматически.

## Что подтверждено в текущей версии репозитория

- `translate-core.js` уже извлекает текст из DOCX, EPUB и FB2, но результат сводит к обычному тексту.
- `readDocx()` использует Mammoth `extractRawText()`, поэтому форматирование DOCX теряется.
- `readEpub()` извлекает текст из XHTML и не собирает EPUB обратно.
- `readFb2()` извлекает текст из XML и не собирает FB2 обратно.
- `showResult()` показывает plain text; `bindDownloads()` скачивает только TXT.
- `document-counter.js` есть, но не подключён в `index.html`; обработчик загрузки не отправляет ожидаемое событие.
- `calculator.js` сейчас использует одну общую базовую ставку и множители по категории, а не отдельную матрицу тарифов по каждому формату и услуге.
- В калькуляторе уже есть три режима (Перевод/Конвертация/Редакция), валюты RUB/KZT/USD/EUR, язык, объём, формат и срок.
- В `admin.js` есть просмотр последних заявок и смена статусов. Поля просмотра: имя/email, услуга, язык, формат, символы, контакт, оплата, сумма, дата, ссылка на файл, комментарий.
- Серверная часть хранит заявки в D1, отправляет Telegram/Resend при настройке секретов. `wrangler.toml` содержит заглушку `REPLACE_WITH_CLOUDFLARE_D1_DATABASE_ID`.
- Кабинет/админка и API требуют корректного развёртывания Cloudflare Pages Functions + D1 + Cloudflare Access. GitHub Pages не исполняет Functions.

## Включённые файлы

- `epub-fb2-processor.js` — новый модуль, который переводит текстовые узлы XHTML внутри EPUB и XML внутри FB2, сохраняя структуру элементов и ссылки на стили/изображения. Для EPUB нужен JSZip.
- `document-counter.js` — модуль статистики: символы, слова, стандартные страницы по 1800 символов и ориентир страниц по 250 слов; отправляет объём в калькулятор.

## Важные ограничения честной проверки

- Перевод EPUB/FB2 с сохранением структуры требует интеграции модуля в `translate-core.js`; просто загрузить файл модуля в GitHub недостаточно.
- EPUB-архив должен быть проверен на реальных EPUB2/EPUB3 образцах; точное сохранение исходного порядка ZIP-записей JSZip не гарантирует.
- Для FB2 необходимо проверить реальные файлы с разными кодировками и namespaces.
- DOCX пока нельзя считать сохраняющим исходный дизайн: текущая реализация извлекает только текст.
- OCR сканов PDF/фото нужно тестировать на реальных изображениях, языках и качестве.
- Ни одна динамическая проверка в браузере не выполнена этим пакетом.

## Установка

1. Сначала скачайте ZIP и распакуйте.
2. Скопируйте `epub-fb2-processor.js` в корень репозитория.
3. Замените `document-counter.js` одноимённым файлом из пакета.
4. В `index.html` добавьте блок статистики рядом с полем текста/загрузкой:

   ```html
   <section id="documentStats" class="mk-card hidden" aria-live="polite">
     <h3>Объём документа</h3>
     <p>Символов: <strong id="docStatCharacters">0</strong></p>
     <p>Слов: <strong id="docStatWords">0</strong></p>
     <p>Стандартных страниц (1800 символов): <strong id="docStatStandardPages">0</strong></p>
     <p>Ориентир по 250 слов: <strong id="docStatWordPages">0</strong></p>
     <p>Физических страниц: <strong id="docStatPhysicalPages">—</strong></p>
     <p id="docStatSource"></p>
   </section>
   ```

5. Внизу `index.html` подключите скрипты в порядке:
   ```html
   <script src="epub-fb2-processor.js"></script>
   <script src="translate-core.js"></script>
   <script src="document-counter.js"></script>
   <script src="calculator.js"></script>
   ```
   Сохраните остальные существующие скрипты (`api.js`, `order.js`, `app.js`) и не дублируйте подключения.

6. В `translate-core.js` после успешного извлечения файла отправляйте событие:
   ```js
   window.dispatchEvent(new CustomEvent('mirror-info:document-loaded', {
     detail: { text: selectedFileText, fileName: file.name }
   }));
   ```
   Здесь `file` — выбранный файл; вставлять событие нужно после успешного присвоения `selectedFileText`.

7. После очистки файла отправляйте:
   ```js
   window.dispatchEvent(new Event('mirror-info:document-cleared'));
   ```

## Интеграция перевода EPUB/FB2

Модуль предоставляет:
- `MirrorDocumentProcessor.translateEpub(file, translateText, onProgress)`
- `MirrorDocumentProcessor.translateFb2(file, translateText, onProgress)`

`translateText` — async callback, который принимает текстовый фрагмент и возвращает перевод. Встраивать вызов нужно в существующий процесс перевода вместо скачивания TXT для EPUB/FB2. Не подключайте этот модуль, пока не сделана интеграция `translate-core.js`: иначе пользователь увидит прежний TXT-результат.

## Калькулятор: согласованные требования, которые надо сохранить

- Единый калькулятор: «Перевод», «Конвертация», «Редактура».
- Услуга, формат, язык, объём; ввод объёма в страницах или словах.
- Ориентир: 250 слов на страницу; отдельно стандартная страница 1800 символов, если расчёт ведётся по символам.
- Валюты: ₸, ₽, $, €; курс обновляется автоматически при доступности сервиса, иначе явно обозначается как базовый/ориентировочный.
- Пример для DOCX, русский, 20 страниц: перевод — 48 000 ₸ (2–3 рабочих дня); конвертация — 14 000 ₸ (1–2 рабочих дня); редактура — 30 000 ₸ (2–3 рабочих дня).
- Ставки 2400/700/1500 ₸ за страницу обсуждались как производные предварительные значения, НЕ утверждённые тарифы.
- Тарифы должны отличаться по формату: DOCX, PDF, EPUB, FB2 и прочим форматам. Не подставлять тариф DOCX для PDF/EPUB/FB2.
- Услуги можно заказывать вместе.
- После просмотра документа стоимость и срок могут уточняться.

## Админка и заявки: сохранить

- Не удалять существующие D1 API и таблицы.
- Сохранить статусы: «Новая», «В работе», «Выполнена», «Отменена».
- Сохранить контакты, язык, формат, объём, способ оплаты, сумму, комментарий и дату.
- Для просмотра/скачивания оригиналов нужна серверная загрузка и защищённое хранилище R2, а не только публичная ссылка из поля `orderLink`.
- Для уведомлений нужны секреты Telegram и/или Resend на стороне Cloudflare.
- Не размещать токены/пароли в HTML/JS и GitHub.
- Не выдавать админку за работающую, пока настроены D1, Cloudflare Access и Pages Functions.

## Тарифы, которые пока нельзя зафиксировать автоматически

В доступном согласованном контексте есть только пример DOCX на 20 страниц для трёх услуг. Точная полная тарифная таблица для PDF, EPUB, FB2, RTF, TXT, сканов и фотографий не восстановлена в виде утверждённых чисел. Поэтому текущие расчётные ставки `calculator.js` нельзя молча объявить правильными и нельзя заменить выдуманными числами. Следующий шаг — внести полную матрицу тарифов в отдельную конфигурацию после восстановления всех утверждённых сумм.
