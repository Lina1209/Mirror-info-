MIRROR-INFO — АВТОМАТИЧЕСКИЙ СЧЁТЧИК
Пакет подготовлен для текущей структуры репозитория Lina1209/Mirror-info- (ветка main).

Что делает:
- автоматически считает символы с пробелами после чтения загруженного файла;
- считает стандартные страницы: символы / 1800;
- считает физические страницы PDF;
- для одного изображения показывает 1 физическую страницу;
- считает текст при ручном вводе/вставке;
- передаёт объём в существующий калькулятор, а через calculator.js — в поле orderChars формы заказа;
- автоматически выбирает категорию формата для калькулятора: text / document / scan.

Файлы пакета:
1. document-counter.js — новый файл, загрузить в корень репозитория рядом с index.html.
2. counter-panel.html — HTML-фрагмент, вставить в index.html в указанное место.
3. counter.css — CSS-фрагмент, добавить в конец style.css.
4. translate-core-counter-patch.txt — точечные дополнения к существующему translate-core.js.
5. index-script-line.txt — строка подключения нового JS.

Порядок установки:
1. Сначала сделайте резервные копии index.html, style.css и translate-core.js (можно скачать текущие версии из GitHub).
2. Загрузите document-counter.js в корень репозитория.
3. В index.html вставьте содержимое counter-panel.html после блока panelPhoto и перед блоком выбора языков.
4. В index.html найдите внизу:
   <script src="translate-core.js"></script>
   <script src="calculator.js"></script>
   Между ними вставьте:
   <script src="document-counter.js"></script>
5. Добавьте содержимое counter.css в самый конец style.css.
6. В translate-core.js внесите только точечные дополнения из translate-core-counter-patch.txt.
7. Сохраните изменения и дождитесь GitHub Pages deployment.
8. Проверьте вручную: TXT, ручной ввод, DOCX, PDF с текстом, PDF-скан и фотографию.

ВАЖНО:
- calculator.js менять не требуется: текущий файл уже слушает событие input поля calcChars и переносит значение в orderChars.
- Счётчик считает извлечённый текст, а не размер файла в байтах.
- Стандартная страница — расчётная единица 1 800 символов с пробелами. Значение может быть дробным.
- Физическое число страниц надёжно показывается только для PDF и отдельной картинки. Для DOCX/EPUB/FB2 число печатных страниц зависит от оформления и не выводится из извлечённого текста.
- Пакет ещё не установлен в репозиторий и не прошёл браузерное тестирование на телефоне. После установки нужно проверить все перечисленные типы файлов.
