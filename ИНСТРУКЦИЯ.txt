MIRROR-INFO — ПАКЕТ CLOUDflare PAGES + D1
==========================================

Назначение
---------
Этот архив подготавливает минимальные файлы для проверки D1 и сохранения заявок.
Он не выполняет публикацию автоматически и не меняет GitHub сам.

Состав и пути
------------
1) functions/api/health.js
   Проверяет наличие привязки DB и двух обязательных таблиц.

2) migrations/0001_initial.sql
   Создаёт таблицы orders и order_rate_limits, если их ещё нет.

3) functions/api/orders.js
   Сохраняет текущую логику проекта и исправляет сравнение времени лимита
   заявок через julianday(created_at).

4) _routes.json
   Добавляет маршрут /api/health в список Pages Functions.

Порядок установки
-----------------
1. Сначала скачайте резервную копию текущих файлов репозитория.
2. Распакуйте архив в корень репозитория Mirror-info-.
3. Замените functions/api/orders.js и _routes.json.
4. Добавьте functions/api/health.js и migrations/0001_initial.sql.
5. Проверьте, что в Cloudflare Pages для проекта настроена D1-привязка:
      Variable name / Binding: DB
   Имя привязки должно быть именно DB.
6. Примените миграцию к нужной D1 базе из каталога migrations.
   Для Wrangler CLI команда обычно выглядит так:
      npx wrangler d1 migrations apply mirror-info-orders --remote
   Выполняйте её только если имя базы в Cloudflare действительно mirror-info-orders
   и вы выбрали правильный аккаунт/проект.
7. Убедитесь, что в wrangler.toml указан настоящий database_id из Cloudflare.
   Не заменяйте его заглушкой и не меняйте ID наугад.
8. Опубликуйте Cloudflare Pages deployment.

Проверка
--------
Откройте в браузере:
   https://ВАШ-ДОМЕН/api/health

Успешный ответ должен содержать:
   "ok": true
   "database": "connected"
   "schema": "ready"

Если database = not_configured:
   проверьте D1 binding DB в настройках Cloudflare Pages.

Если schema = incomplete:
   примените миграцию к той же D1 базе, которая подключена как DB.

Если вернулся 404:
   проверьте deployment, каталог functions и _routes.json.

Затем отправьте одну тестовую заявку через форму сайта и проверьте,
что она появилась в таблице orders. Не отправляйте много тестов подряд:
лимит — 5 заявок с одного IP за 10 минут.

Важно
-----
- Cloudflare Pages Functions не исполняются на GitHub Pages.
- Этот пакет не меняет wrangler.toml, потому что его Database ID должен
  соответствовать реальной D1 базе.
- Уведомления Telegram и email отправляются только при наличии настроенных
  секретов/переменных окружения.
- Не помещайте токены, пароли и секреты в GitHub или в этот архив.
- Перед заменой файлов сохраните резервные копии.
